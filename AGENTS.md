# Engineering Reference Agent Contract

These instructions apply to the entire repository.

Before performing task work, read and follow
[`docs/ai-assisted-development.md`](docs/ai-assisted-development.md). It is the
canonical project-local profile for sources of truth, task readiness, workflow
selection, authority, checkpoints, verification, review, and durable handoff.

Read the governing product and technical documents routed by that profile for
the area being changed. Follow the accepted GitHub issue contract and its
recorded working approach. When instructions, requirements, or authorities
conflict, stop and surface the conflict instead of guessing which one to
override.

The central Agent-Assisted Engineering Playbook is supplementary guidance; the
local profile is the operational authority for this repository.
