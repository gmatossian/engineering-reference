# Create and run a Spring Boot app — authoring sources

Retrieval job: recover the generation choices, local run commands, and controller
syntax for creating and retrieving a resource. Checked 2026-10-28.

- [IntelliJ Spring Boot project wizard](https://www.jetbrains.com/help/idea/spring-initializr-project-wizard.html): menu path, shared project settings, dependencies, and default Initializr service.
- [Spring Initializr reference](https://docs.spring.io/initializr/docs/current/reference/html/): project-generation service and metadata.
- [Spring Initializr service](https://start.spring.io/): browser generator. The verification fixture was generated by this service with Boot 4.1.2, Java 21, Maven, `ProductsApplication`, and Web MVC/Validation dependencies.
- [Run a Spring Boot application](https://docs.spring.io/spring-boot/reference/using/running-your-application.html): IDE, Maven plugin, executable JAR, and duplicate-port behavior.
- [Actuator endpoints](https://docs.spring.io/spring-boot/reference/actuator/endpoints.html): built-in health endpoint, default HTTP exposure, and health indicator aggregation.
- [Managed dependency coordinates](https://docs.spring.io/spring-boot/appendix/dependency-versions/coordinates.html): managed `org.springframework.boot:spring-boot-starter-actuator` dependency. Also present in the local exercise's Maven configuration.
- [IntelliJ Spring application example](https://www.jetbrains.com/help/idea/your-first-spring-application.html): generated main class, running it, and default HTTP port 8080.
- [Structure Spring Boot code](https://docs.spring.io/spring-boot/reference/using/structuring-your-code.html): root application package and default scanning.
- [MVC request mappings](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-requestmapping.html): REST controller, HTTP method mappings, and path variables.
- [MVC request body](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-methods/requestbody.html): JSON deserialization and `@Valid`.
- [ResponseEntity API](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/http/ResponseEntity.html): `created(URI)` sets HTTP 201 and the Location header.

The controller and record shapes are adapted from the local
`spring-boot-api-practice` exercise. The Topic deliberately shows only the web
boundary, assuming the exercise's service contract and Product getters; it is
not a complete standalone CRUD application. Imports are omitted from snippets.

The authored controller and records were compiled in the generated project with
the exercise's service/repository/model, adapting packages and adding imports.
Both the packaged JAR and Maven development run returned POST 201 with Location
and GET 200 with the matching product JSON. Verified on JDK 25 targeting Java 21.

The Actuator dependency was also checked in a fresh generated app with no
controllers or custom exposure settings. `/actuator/health` returned HTTP 200
with `status: UP` and additional health-group fields; the Topic intentionally
checks the status rather than prescribing an exact response object.
