# Spring and Spring Boot — authoring sources

References for verifying `topic.md`; not rendered in the application. Checked
2026-10-27. The Topic compares Spring with and without Boot, rather than specific
Framework or Boot major versions.

- [Spring Framework overview](https://docs.spring.io/spring-framework/reference/overview.html): the Spring family, core container, optional modules, and web/non-web application scenarios.
- [Spring Framework project](https://spring.io/projects/spring-framework/): infrastructure, dependency injection, transactions, data-access integration, and testing support.
- [Spring MVC](https://docs.spring.io/spring-framework/reference/web/webmvc.html): Servlet-based web framework within Spring Framework.
- [Spring Data](https://spring.io/projects/spring-data/): separate project family providing repository and data-access abstractions.
- [Spring Security](https://spring.io/projects/spring-security/): separate project providing authentication and authorization.
- [Spring Integration](https://spring.io/projects/spring-integration/): message flows, enterprise integration patterns, and adapters for external systems.
- [Spring Batch](https://spring.io/projects/spring-batch/): batch processing, job restart, retry, and Boot integration.
- [Spring Boot project](https://spring.io/projects/spring-boot/): starters, auto-configuration, embedded servers, executable applications, and production features.
- [Boot dependency management and starters](https://docs.spring.io/spring-boot/reference/using/build-systems.html): managed dependency versions and dependency descriptors.
- [Boot auto-configuration](https://docs.spring.io/spring-boot/reference/using/auto-configuration.html): conditional defaults and replacing them with application configuration.
- [Spring Java configuration](https://docs.spring.io/spring-framework/reference/core/beans/java.html): annotation-based configuration is available independently of Boot.
- [Boot traditional deployment](https://docs.spring.io/spring-boot/how-to/deployment/traditional-deployment.html): Servlet applications can use external-container WAR deployment as an alternative to an embedded server.
